# アプリのアイコン

採用したデザインは案24-C(淡いアイス色の本に`md`の文字、背表紙W2・文字サイズS3・上寄せ)です。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `appicon.svg` | 編集用の元データ(ベクター)。文字はパスに変換済み |
| `appicon.png` | Wails用。1024×1024の透過PNG |
| `windows/icon.ico` | Windowsの実行ファイルに埋め込むアイコン。16・20・24・32・40・48・64・128・256pxを収録 |

## ビルドとの関係

`wails build`を実行すると、これらのアイコンがEXEに組み込まれます。

## アイコンを変えるとき

Wailsは、すでにある`windows/icon.ico`を自動では作り直しません。`appicon.svg`を変更したら、**`appicon.png`と`windows/icon.ico`の両方**を自分で作り直してください。
