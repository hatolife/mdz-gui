# 新規mdBookのテンプレート

この文書は、mdz-guiで新しいmdBookを作成したときのテンプレートです。
各ページの文章や構成を、自分の本に合わせて置き換えて使用してください。

## このテンプレートで確認できること

- 章と子章を使った目次構成
- ページ間リンク
- 画像の配置
- 表やコードブロック
- 付録の配置
- mdz-guiでの目次編集

mdBookでは、本に含めるページや並び順を `SUMMARY.md` で管理します。
mdz-guiでは左側のGUIから目次を編集でき、必要に応じて `SUMMARY.md` を直接編集することもできます。

詳しくは[目次と SUMMARY.md](guide/summary.md)を参照してください。

## 編集を始める

右上の **「表示 / 編集」** で編集モードに切り替え、左側の目次から編集したいページを選択します。
本文は右側のエディターで編集できます。

本のタイトルなどは **「本の設定」** から変更できます。
