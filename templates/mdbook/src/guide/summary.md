# 目次と SUMMARY.md

mdBookでは、`SUMMARY.md` が本全体の目次とページ構成を定義します。
本に掲載するMarkdownファイル、章の表示名、並び順、階層などは、このファイルに記述されています。

## mdz-guiで目次を編集する

編集モードで左側の **「目次を編集」** を押すと、目次編集モードになります。

左側のGUIでは、次の操作を行えます。

- ページの追加
- 部タイトルの追加
- 表示名の変更
- 並び替え
- 階層の変更
- 目次からの削除

目次編集モードでは、右側のエディターに `SUMMARY.md` が表示されます。
そのため、左側のGUIを使いながら、必要に応じて `SUMMARY.md` を直接編集できます。

左側のGUIと右側のエディターは、同じ `SUMMARY.md` を編集しています。

## SUMMARY.mdの基本形

例えば、次の記述は2つの章と、そのうち1つの子章を表します。

```markdown
- [第1章 はじめに](guide/editing.md)
    - [図と補足](guide/images.md)
- [第2章 詳細](guide/contents.md)
```

リンクの表示名が目次に表示され、リンク先のMarkdownファイルが本文ページになります。
インデントを付けると、そのページを子章として配置できます。

部タイトルは見出しとして記述できます。

```markdown
# 本文

- [第1章 はじめに](guide/editing.md)
```

区切り線や、通常のリストとは異なるmdBookの記法を使いたい場合は、右側の `SUMMARY.md` を直接編集すると調整しやすくなります。

## 編集方法の使い分け

普段の追加・並び替え・階層変更には左側のGUIを使うと簡単です。
目次の記法を細かく調整したい場合や、複数行をまとめて編集したい場合は `SUMMARY.md` を直接編集してください。

編集が終わったら **「目次の編集を終える」** を押して本文の編集へ戻ります。
