# 画像とリンクを使う

## 画像を貼り付ける

編集中に`Ctrl+V`でスクリーンショットなどを貼り付けると、次のことが自動で行われます。

1. 画像ファイルを文書の中に保存する
2. 本文に画像へのリンクを挿入する

「画像追加」ボタンから、ファイルを選んで入れることもできます。

![本の構成](../images/book.svg)

上の画像も、このヘルプと一緒にMDZに保存されています。本文にBase64で埋め込む必要はありません。

## 元に戻したとき

画像を貼った後に「元に戻す」をすると、本文のリンクだけが消えます。画像ファイルは残っているので、「やり直す」で元どおりになります。

使われなくなった画像は、自動では削除されません。

## 画像の保存先と名前

保存先のフォルダーとファイル名の付け方は、「設定」で変えられます。

- 保存先の既定は`images`です(mdBookでは`src/images`)。
- 名前の既定は`{date}-{time}-{counter}`です。
- 同じ名前の画像があっても、上書きはしません。

## ほかのページへのリンク

[目次を組み立てる](contents.md)のように、ほかのページへリンクできます。リンク先はファイルの相対パスで書きます。
