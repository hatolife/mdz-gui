# 目次を組み立てる

mdBookでは、左側の目次が**この本を読む順番**です。フォルダーやファイル名の並びとは関係ありません。

## 目次でできること

編集モードで目次の「編集」を押すと、次の操作ができます。

| 操作 | 結果 |
| --- | --- |
| ページを追加 | 新しいページを作って目次に入れる |
| 名前を変更 | 目次に出る章の名前を変える |
| 上下へ移動 | 読む順番を変える |
| 右へ下げる | 直前の章の子ページにする |
| 左へ戻す | ひとつ上の階層に戻す |
| 目次から外す | 目次から消す。本文は残る |

目次から外したページは、「目次にないページ」から戻せます。

目次の操作は、本文とは別に「元に戻す / やり直す」ができます。

## 保存のしくみ

目次の変更は、自動で`SUMMARY.md`に書き込まれます。`SUMMARY.md`は目次を定義するファイルなので、本文のページとしては表示しません。

`SUMMARY.md`にあるコメントや、mdz-guiが扱えない書き方は、そのまま残します。細かい調整をしたいときは、`SUMMARY.md`を直接編集してください。

## 本文を書くとき

本文を編集するには、目次からそのページを選んでください。
