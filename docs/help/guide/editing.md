# ページを編集する

## 編集を始める

右上の「表示 / 編集」を押すと編集モードになります。もう一度押すと表示モードに戻ります。表示モードに戻っても、未保存の変更は消えません。

編集モードでは、画面の分け方を次から選べます。

- 本文のみ
- 本文とプレビューを並べる
- プレビューのみ

## エディターを選ぶ

上部の「内蔵 / Neovim」で、使うエディターを切り替えます。

| エディター | 特徴 |
| --- | --- |
| 内蔵 | そのまま使える。`Ctrl+Z` / `Ctrl+Y`で元に戻す / やり直す |
| Neovim | 本物のNeovim。`:w`で保存、`u` / `Ctrl+R`で元に戻す / やり直す |

起動時にどちらを使うかは、「設定」の「編集方式」で決めます。Neovimが見つからない場合は内蔵エディターになります。

## Markdownの例

**太字**、*斜体*、`コード`を使えます。

- 短いメモを書く
- 手順を説明する
- 図や画像を添える

> 目次に表示される名前と、ページ先頭の見出しは別のものです。目次の名前を変えても、本文は変わりません。

```go
func message() string {
	return "Hello, mdBook!"
}
```

次は[画像とリンクを使う](images.md)へ進んでください。

## ページを追加する(通常のMDZ)

編集モードで「ページ追加」を押し、名前を入力します。

| 入力 | 作られるファイル |
| --- | --- |
| `はじめに` | `はじめに.md` |
| `chapters/補足` | `chapters/補足.md` |

拡張子を省略すると`.md`が付きます。新しいページは一覧の最後に入ります。

mdBookでは目次から、スライドではサムネイル一覧からページを追加します。

## ページを並べ替える(通常のMDZ)

左の「ページ」タブで、ページをドラッグして別のページに重ねます。

- 相手の**上半分**に落とすと、その前へ移動します。
- 相手の**下半分**に落とすと、その後ろへ移動します。

フォルダーが違うページ同士でも並べ替えられます。並び順はMDZに保存され、ファイル名やリンクは変わりません。

「ファイル」タブでは、MDZの中のフォルダーや画像を確認できます。

## 外部のMarkdownを取り込む

パソコン上の`.md`ファイルを、左のページ一覧・目次・サムネイル一覧へドラッグ&ドロップします。落とした位置に、コピーがページとして入ります。元のファイルは変更しません。

一覧以外の場所に落とした場合は、取り込みではなく「開く」になります。

## 単一Markdownを編集する

`.md`ファイルを開くと、MDZに変換せずそのまま編集します。

- `Ctrl+S`で元のファイルに上書きします。
- 相対パスの画像は、Markdownファイルがあるフォルダーを基準に表示します。
- ページを増やしたり画像を同梱したりするには、`Ctrl+Shift+S`で「MDZとして保存」します。
