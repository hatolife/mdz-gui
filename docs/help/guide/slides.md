# スライドを作って発表する

Markdownで発表資料を作り、そのまま発表できます。追加のインストールやインターネット接続は不要です。

## 作る

1. 「新規」→「スライドを作成」を押します。8ページのサンプル資料ができます。
2. 左のサムネイルからページを選び、Markdownを編集します。**1ファイルが1枚のスライド**です。
3. サムネイルを右クリックし、「スライドを追加」か「複製」でページを増やします。
4. サムネイルをドラッグして並べ替えます。挿入される位置に点線が出ます。
5. `Ctrl+S`で保存します。本文・画像・構成・ノートが1つのMDZになります。

## 見た目を変える

| 画面 | 変えられるもの |
| --- | --- |
| 資料・ページ設定 | 資料タイトル、ライト / ダーク、16:9 / 4:3、ページの表示名、レイアウト、背景色、余白の色、発表者ノート |
| 文字・ページ | フォントの種類、本文とH1〜H5の文字サイズ、要素枠の表示 |

見出しの文字サイズは、常にH1 > H2 > H3 > H4 > H5の順に保たれます。

## レイアウト

「標準」「表紙」「画像中心」「左右2列」の4つから選べます。

「左右2列」では、前後を空行で挟んだ`<!-- column -->`で左右を分けます。

```markdown
# 左の見出し

左の本文

<!-- column -->

# 右の見出し

右の本文
```

## 画像を入れる

次のどれかで入れられます。外部URLの画像は表示しません。

- 右クリック→「画像追加」
- `Ctrl+V`で貼り付け
- 画像ファイルをドラッグ&ドロップ

## はみ出したとき

内容がスライドに収まらないと警告が出ます。自動で改ページしたり文字を縮めたりはしません。

- 編集プレビューの**黒い枠**がスライドの範囲です。はみ出た部分も枠の外に見えます。
- 「文字・ページ」で要素枠を表示すると、各要素の範囲がわかります。

直しかたは2つあります。

| 方法 | 手順 |
| --- | --- |
| 文字を小さくする | 「文字・ページ」で文字サイズを下げる |
| 2枚に分ける | 分けたい所に`---`だけの行を入れ、「ページ分割」を押す |

本文中の`---`は、普段は水平線として表示されます。ページが分かれるのは「ページ分割」を押したときだけです。コードブロック内の`---`では分割しません。

## 発表する

「最初から発表」か「このページから発表」を押すと、全画面で発表が始まります。

| 操作 | キー・マウス |
| --- | --- |
| 次へ | →、↓、Enter、PageDown、Space、ホイール下、スライドの右側をクリック |
| 前へ | ←、↑、Shift+Enter、PageUp、ホイール上、スライドの左側をクリック |
| 最初 / 最後へ | Home / End |
| 一覧表示 | O |
| 発表を終了 | Esc または右クリック |

スライドの中央付近をクリックしても移動しません。本文中のリンクはクリックで開きます。

## 2画面で発表する

プロジェクターに投影しながら、手元でノートや次のスライドを見られます。

1. 「資料・ページ設定」で、各ページに発表者ノートを書いておきます(任意)。
2. 「2画面で発表」を押します。今のウィンドウが発表者用になり、投影用のウィンドウが別に開きます。
3. 投影用ウィンドウを、マウスでプロジェクター側の画面へ移動します。
4. `F`キーか「投影を全画面にする」で、投影用ウィンドウを全画面にします。
5. 発表者の画面で操作すると、投影側も一緒に切り替わります。
6. 「発表を終了」、Esc、右クリックのどれかで終了します。

発表者の画面には、現在時刻・経過時間・前後のスライド・ノートが出ます。タイマーは一時停止・再開・リセットできます。

- 発表中に内容を編集しても、投影には反映されません。いったん終了して発表し直してください。
- ノートは投影用ウィンドウには送られません。

## 元に戻す

| 対象 | 方法 |
| --- | --- |
| 本文 | ツールバーの↶ / ↷、またはエディターのUndo / Redo |
| ページの追加・削除・並べ替え・設定 | 右クリック→「構成を元に戻す」「構成をやり直す」 |

構成の「元に戻す」は、文書を開いている間だけ使えます。

## Markdownを取り込む

右クリック→「Markdownを取り込む」で、貼り付けたMarkdownを`---`で区切ってスライドにします。選んでいるページの後ろに追加されます。

- 前後を空行で挟んだ`---`で区切ります。コードブロック内では区切りません。
- 先頭のYAML(Front Matter)は消しておいてください。
- Marp独自の書き方の変換や、画像の自動取り込みはしません。

## 注意点

- スライドは最大500枚です。
- 一覧から削除しても、本文と画像はMDZ内に残ります。
- 発表者ノートはMDZに保存されます。**資料を人に渡すと、ノートも読まれます。**
- PDF・HTML・PowerPointへの書き出しと、段階表示には対応していません。
- 異常終了したときは、右クリックメニューの「作業データの復旧」から開き直せます。
