# 本の設定と保存

## 本のタイトルを変える

編集モードで、左側の本のタイトル横にある「変更」を押します。

## 本の設定(book.toml)

編集モードで左下に出る「本の設定」を押すと、`book.toml`を編集できます。`book.toml`は本全体の設定ファイルで、本文ページではありません。

| 設定 | 意味 |
| --- | --- |
| `title` | 本のタイトル |
| `authors` | 著者の一覧 |
| `language` | 本の言語。日本語は`ja` |
| `src` | 本文と目次を置くフォルダー |

保存前に書式の誤りをチェックします。コメントや独自の設定は消えません。保存するとプレビューも更新されます。

## mdBookのプレビュー

mdBookの文書を開くと、自動でプレビューを表示します。mdBookがパソコンにない場合は、wingetでインストールするか確認します。インストールしない場合は通常のMDZとして表示し、あとから「設定」の「mdBookをインストール」で入れられます。

wingetが使えない場合は、画面の「導入方法」を見て手動で入れるか、「実行ファイルを指定」で`mdbook.exe`の場所を指定してください。

## 保存する

「保存」か`Ctrl+S`で、本文・目次・設定・画像をまとめて1つのMDZに保存します。プレビュー用に作られたHTMLは含めません。

未保存のまま閉じようとすると、次の3つから選べます。

| ボタン | 動作 |
| --- | --- |
| 保存 | 保存してから閉じる |
| 破棄 | 変更を捨てて閉じる |
| キャンセル | 閉じるのをやめる |

## バックアップと復旧

- 上書き保存の直前のファイルは、自動でバックアップされます(既定で10世代)。
- アプリが異常終了したときは、次回「作業データの復旧」から続きを開けます。

## 必要なアプリの確認

「設定」では、mdBook・Neovim・`init.lua`が見つかったかどうかと、その場所を確認できます。表示が古いときは「存在を再確認」を押してください。

`init.lua`の場所を空欄にすると、Neovimの標準の場所から探します。見つからなければ、設定なし(`--clean`)でNeovimを起動します。
