# mdz-gui ヘルプ

mdz-guiは、Markdownを読み書きするWindowsアプリです。このヘルプ自体も、mdz-guiで作った通常のMDZです。

## 扱える文書

| 種類 | 向いている用途 |
| --- | --- |
| 単一Markdown(`.md`) | 既存のMarkdownをそのまま編集する |
| 通常のMDZ(`.mdz`) | 画像付きのメモや資料。複数ページも可 |
| mdBook(`.mdz`) | 章立てのある本やマニュアル |
| スライド(`.mdz`) | 発表資料 |

MDZは、本文・画像・構成情報を1つにまとめたファイルです。中身はZIPなので、普通のZIPツールでも取り出せます。

## 文書を開く

- 左端の「開く」を押すか、ファイルをウィンドウへドラッグ&ドロップします。
- 既存の文書は「表示モード」で開きます。書き換えるときは、右上の「表示 / 編集」で編集モードにします。
- すでに文書を開いているウィンドウへ別の文書をドロップすると、新しいウィンドウで開きます。

## 新しく作る

左端の「新規」から、作りたい種類を選びます。新規作成した文書は、すぐ編集できる状態で開きます。

| ボタン | できるもの |
| --- | --- |
| 通常のMDZを作成 | `本文.md`が1ページ入った文書 |
| mdBookを作成 | 章・図・表・付録のひな形が入った本 |
| スライドを作成 | 8ページのサンプル資料 |

## コマンドライン

```sh
mdz-gui.exe document.mdz   # ファイルを指定して開く
mdz-gui.exe --help         # 使い方を表示
mdz-gui.exe --version      # バージョンを表示
```
